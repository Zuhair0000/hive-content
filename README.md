# 🐝 Hive Content — AI Content Plan Generator

Hive Content turns a short business brief into a **complete, ready-to-publish social media content plan** using Google Gemini. For every post it writes the hook, idea, word-for-word script, caption, hashtags, call to action and filming suggestions, then lays the plan out on a posting schedule.

## How it works
1. **Brief:** the user describes the business: name, target audience, content type (such as Reels), plan duration, posting frequency and extra details.
2. **Generation:** the backend builds a structured prompt and sends it to **Google Gemini**. The prompt sets how many posts to create from the duration and frequency, and how long each script should be for the content type.
3. **Structured output:** Gemini returns **strict JSON**, which the backend parses into separate content items.
4. **Storage:** each plan is saved as a draft with its content items in **PostgreSQL**, linked to the user's account.
5. **Review:** the user opens the plan to read, edit or delete each post, and switches to the schedule view to see the posting order.

## Example output
For a travel agency targeting travellers from Yemen, Hive Content generated posts such as *"Need a Break? Discover Your Dream Vacation!"* and *"Top 3 Easy-to-Visit Destinations for Yemeni Travelers"*. Each came with a full script, caption, hashtags, call to action and visual suggestions.

## Features
- **AI content plans** for any business and audience, generated by Google Gemini
- **Complete posts:** title, idea, ready-to-record script, caption, hashtags, call to action and visual suggestions
- **Dashboard** listing every plan the user has created
- **Content and Schedule tabs:** manage posts in detail, or see them on a posting timeline
- **Edit and delete** individual posts
- **Secure accounts** with bcrypt password hashing and JWT authentication

## Tech stack
**Frontend:** React · Vite · Tailwind CSS · React Router
**Backend:** Node.js · Express · PostgreSQL (Supabase) · JWT · bcrypt
**AI:** Google Gemini API (`@google/genai`)

## API endpoints
All content endpoints require a valid JWT.

| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/content/generate` | Generate a new content plan with Gemini |
| GET | `/api/content` | List the user's plans |
| GET | `/api/content/:draftId` | Get all posts in a plan |
| PUT | `/api/content/edit/:id` | Edit a post |
| DELETE | `/api/content/delete/:id` | Delete a post |

## Run it locally
1. **Database:** create a PostgreSQL database (a free Supabase project works) and run `database/schema.sql`.
2. **Backend:**
   ```bash
   cd backend
   cp .env.example .env    # fill in your database details, JWT secret and Gemini API key
   npm install
   npm start
   ```
3. **Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
4. Open http://localhost:5173, create an account and generate a plan.

Get a free Gemini API key from [Google AI Studio](https://aistudio.google.com).
